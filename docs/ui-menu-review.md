# بررسی فیچرها و ساختار منوی Rozet UI

## فیچرهای پیاده سازی شده

- احراز هویت: ورود با ایمیل، نگه داشتن نشست، خروج، بازیابی رمز عبور، ثبت رمز عبور جدید.
- داشبورد اصلی: کارت های آماری، روند فروش، فعالیت های اخیر، جست وجوی سراسری ظاهری.
- اعلان ها: شمارنده اعلان خوانده نشده، فهرست اعلان ها، خواندن یک اعلان، خواندن همه اعلان ها.
- مدیریت وظایف: داشبورد وظایف، فهرست همه وظایف، برد کانبان، تقویم پروژه، جلسات و صورت جلسات، گردش کار و الگوها، ماتریس RACI.
- چت آنلاین: فهرست گفتگوها، پیام ها، جست وجو، شروع گفتگوی مستقیم یا گروهی، ارسال پیام، اتصال SignalR.
- مدیریت کاربران: فهرست کاربران، ایجاد کاربر، ویرایش اطلاعات حساب و پروفایل، فعال/غیرفعال کردن، اختصاص نقش.
- کنترل دسترسی: نقش ها، گروه های کاربری، اختصاص مجوز به نقش/گروه/کاربر، نمایش مجوزهای ارث بری شده.
- تاریخچه ورود و رویدادها: نمایش audit log با صفحه بندی.
- چارت سازمانی: نمایش سلسله مراتب نقش ها و اعضای هر بخش.

## نکته اتصال به Core Platform

گزینه هایی مثل مدیریت مستندات، برنامه ریزی پروژه، کنترل پیشرفت، ریسک، منابع، هزینه، ذینفعان، تامین کنندگان، تغییرات، مدیریت دانش، داشبورد مدیریتی و تنظیمات فعلا صفحه placeholder دارند. هنگام بررسی Core Platform باید برای هر کدام endpoint، permission، مدل داده و صفحه عملیاتی متناظر تعریف یا تکمیل شود.
