# هدیه‌ی روز دختر 🌷

سایت استاتیک (بدون backend و بدون build). همه‌ی فایل‌های قابل انتشار توی پوشه‌ی `site/` هستن.

## ویرایش پیام‌ها
فایل `site/data.js`: متن، رنگ و شکل گل هر نفر. می‌تونی هر پاراگراف رو عوض کنی یا اضافه کنی.

## تست روی کامپیوتر
```
cd site && python3 -m http.server 8000
```
بعد برو `http://localhost:8000/cards.html` و روی لینک هر کارت اسکن/باز کن.

## انتشار رایگان
یکی از این‌ها، فقط پوشه‌ی `site` رو آپلود کن:
- **Cloudflare Pages**: Workers & Pages ← Create ← Pages ← Upload assets ← پوشه‌ی `site` رو بکش.
- **GitHub Pages**: پوشه‌ی `site` رو توی یه ریپوی جدا بذار (یا با GitHub Actions منتشرش کن).
- Netlify Drop (app.netlify.com/drop) هم کار می‌کنه، ولی ممکنه برای بعضی IPهای ایرانی باز نشه.

## ساخت QR و کارت‌ها
بعد از انتشار، آدرس `https://آدرس-سایت-تو/cards.html` رو باز کن. آدرس خودکار پر میشه و QR هر نفر ساخته میشه.
«چاپ همه‌ی کارت‌ها» رو بزن، یا برای هر نفر «دانلود PNG» رو بگیر.

## نکته‌ی حریم خصوصی
لینک هر نفر یه کد تصادفی داره (`?k=...`) پس کسی نمی‌تونه با حدس زدن اسم، پیام بقیه رو ببینه.
ولی چون سایت استاتیکه، متن پیام‌ها داخل `data.js` هست و کسی که بلد باشه سورس صفحه رو ببینه می‌تونه بخونتشون.
